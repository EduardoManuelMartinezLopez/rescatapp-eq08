# RescatApp

Plataforma web para rescatar excedentes de alimentos en Oaxaca de Juárez (ODS 2 y ODS 12).
Conecta **donantes** (negocios), **receptores** (comedores y bancos de alimentos validados) y **administradores**.

Proyecto integrador – Gestión de Proyectos de Software – Instituto Tecnológico de Oaxaca – Equipo 8.

## Estructura
| Carpeta | Contenido |
|---|---|
| `database/` | Script SQL de PostgreSQL (tablas, restricciones, datos de demostración) |
| `backend/` | API REST (Node.js + Express) |
| `frontend/` | Aplicación web (React + Vite + Tailwind) |
| `docs/` | Documentación y diseño de interfaces (Stitch/Figma) |

## Base de datos
1. Crear la base `rescatapp` en PostgreSQL.
2. Ejecutar `database/rescatapp_database.sql`.
